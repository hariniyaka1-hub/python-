# Retail Sales Analysis

## About
This is my data analysis project using Python. In this project, I analyzed a retail sales dataset to understand sales performance and generate business insights.

## What I Did
- Loaded the dataset
- Cleaned and explored the data
- Analyzed sales and profit
- Compared regions and categories
- Created charts and graphs
- Generated business insights

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Files
- `Sales.ipynb` – Project notebook
- `superstore_sales.csv` – Dataset

## How to Run
1. Open the notebook in Jupyter Notebook or Google Colab.
2. Install the required libraries.
3. Run all the cells.
