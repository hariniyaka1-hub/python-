# Wine Quality Prediction

## About
This is my machine learning project using Python. In this project, I analyzed the Wine Quality dataset and built a model to predict the quality of wine.

## What I Did
- Loaded the dataset
- Explored the data
- Checked missing values and duplicates
- Performed data preprocessing
- Trained a Decision Tree model
- Evaluated the model
- Predicted wine quality

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Files
- `Wind.ipynb` – Project notebook
- `winequality-red.csv` – Dataset

## How to Run
1. Open the notebook in Jupyter Notebook or Google Colab.
2. Install the required libraries.
3. Run all the cells.

## Learning Outcome
This project helped me understand data preprocessing, machine learning, and classification using the Wine Quality dataset.
