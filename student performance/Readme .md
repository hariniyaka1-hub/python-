# Student Data Analysis Project

## About
This is my first data analysis project using Python. In this project, I analyzed a student dataset and learned how to clean data, explore it, and create charts.

## What I Did
- Loaded the dataset
- Checked missing values
- Viewed basic statistics
- Found outliers
- Created charts and graphs
- Learned basic data analysis

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Files
- `first_project.ipynb` - Project notebook
- `student_data.csv` - Dataset

## How to Run
1. Open the notebook in Jupyter Notebook or Google Colab.
2. Install the required libraries.
3. Run all the cells.

This project helped me understand the basics of data analysis and data visualization using Python.
