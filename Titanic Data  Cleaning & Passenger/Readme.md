# Titanic Survival Prediction

## About
This is my second machine learning project using Python. In this project, I used the Titanic dataset to predict whether a passenger survived or not.

## What I Did
- Loaded the Titanic dataset
- Cleaned the data
- Handled missing values
- Encoded categorical data
- Trained a Decision Tree model
- Evaluated the model
- Made predictions

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Files
- `second.ipynb` – Project notebook
- `titanic.csv` – Dataset

## How to Run
1. Open the notebook in Jupyter Notebook or Google Colab.
2. Install the required libraries.
3. Run all the cells.

## Learning Outcome
This project helped me learn the basics of data preprocessing, machine learning, and prediction using the Titanic dataset.
