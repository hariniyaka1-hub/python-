# Diamond Price Analysis

## About
This is my data analysis project using Python. In this project, I analyzed a diamond dataset to understand how different features affect the price of diamonds.

## What I Did
- Loaded the dataset
- Explored the data
- Checked missing values and duplicates
- Analyzed diamond prices
- Created charts and graphs
- Found useful insights from the data

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Files
- `Diamond.ipynb` – Project notebook
- `diamonds.csv` – Dataset

## How to Run
1. Open the notebook in Jupyter Notebook or Google Colab.
2. Install the required libraries.
3. Run all the cells.
